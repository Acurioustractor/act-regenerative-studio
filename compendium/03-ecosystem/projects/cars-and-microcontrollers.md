# Cars and microcontrollers

**Learning by making - hands on skills that build confidence.**

Cars and Microcontrollers is a hands-on learning program using practical making - working on vehicles and electronics - as a pathway to skills, confidence, and connection.

---

## Purpose

Not everyone learns from books. Some people need to have something in their hands, need to see something work, need to build. This program provides:

- **Practical skills** - Mechanical and electronic know-how
- **Problem solving** - Debugging real things
- **Confidence** - Making something work builds belief
- **Pathways** - Skills that lead to employment
