## Contributing

When updating the compendium:

1. **Use consistent frontmatter** - See [Website Integration](03-ecosystem/website-integration.md) for schema
2. **Update cross-links** - Check that "See also" links remain valid
3. **Add to changelog** - Document changes here
4. **Mark shareability** - Use INTERNAL/EXTERNAL-LITE/EXTERNAL tags
5. **Update glossary** - Add new terms as they emerge
