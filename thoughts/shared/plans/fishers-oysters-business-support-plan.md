## Innovation Project Agent Concept

**Ben's idea:** An agent that looks across ALL ACT projects and suggests:
- Where more information is needed
- How to get it (client interviews, photo shoots, video, etc.)

### Agent Capabilities

```
Innovation Project Agent
├── Content Audit
│   ├── Check Notion completeness
│   ├── Check Empathy Ledger stories
│   ├── Check media assets (photos/video)
│   └── Check website content
├── Gap Analysis
│   ├── Missing stakeholder interviews
│   ├── Missing visual documentation
│   ├── Incomplete business plans
│   └── Outdated information
├── Action Suggestions
│   ├── Schedule client interview
│   ├── Plan photo shoot
│   ├── Arrange video capture
│   ├── Request document updates
│   └── Identify grant deadlines
└── Cross-Project Insights
    ├── Reusable templates
    ├── Shared resources
    └── Collaboration opportunities
```

### Implementation Path
1. Define project health metrics
2. Build audit scripts to check content completeness
3. Create agent prompt with project context
4. Run weekly/monthly audits
5. Generate action items for each project
