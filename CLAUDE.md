## Commands that are not guessable

```bash
npm run dev           # port 3001 (NOT 3000)
npm run type-check    # tsc --noEmit
npm run check:media   # every photograph on a live story page must resolve; baseline 0
npm run check:copy    # blocks internal-only language in user-facing files
npm run check:consent # blocks a commit that changes what community content is public
npm run hooks:install # point git at scripts/hooks (the tracked pre-commit)
```

There is no `db:types` script, despite what older notes said. Supabase types are
regenerated through the Supabase MCP `generate_typescript_types`, or the CLI.

`npm run build` runs the Empathy Ledger and Notion syncs first, so it hits the
network and is slow. `npx tsc --noEmit && npm run test` is the fast gate.

The contrast and launch gates need a server already running:
`CONTRAST_BASE_URL=<url> node scripts/check-contrast.mjs`.

## Gotchas that have cost time

- **Port 3001 is often The Harvest.** Check before assuming a dev server on 3001
  is this project.
- **Restart the dev server after editing `config/launch-redirects.cjs`.**
  `next.config` reads it once at boot.
- **Never `git commit -am` here.** Modified pages import untracked new files;
  curate the add or the build breaks on deploy.
- **The baked Empathy Ledger snapshots in `src/data/*.generated.json` are a
  stale fallback**, not the truth. Production reads live. Measure rendered pages,
  never the JSON.
- **Vercel's Git integration on push to main is the only deploy path.** Env vars
  apply at build time.
- **The knowledge extractors touch real data.** Gmail and Notion scanners are not
  safe to run casually.

## Voice, beyond the naming rules below

Grounded, plain, peer-to-peer. Metaphor to illuminate, never to obscure.

Avoid: savior narratives, paternalistic framing, luxury positioning, corporate
jargon, glossy marketing speak, overclaiming. For any public-facing copy load
the `act-voice` skill before writing, not after.

### Why this structure

Three trading entities, one charity, one winding-down sole trader. The point is not bureaucracy. Each project earns the right to grow on its own revenue.
