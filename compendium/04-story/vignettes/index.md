# Story Vignettes

We weave story vignettes and community voice through this compendium. Each vignette comes from Empathy Ledger with explicit consent and a clear usage scope. The goal is to foreground lived experience and authority, not decorate the work.

---

## Consent Protocol

**Before using any vignette:**
1. Check consent scope (INTERNAL / EXTERNAL-LITE / EXTERNAL)
2. Confirm cultural review status
3. Verify Empathy Ledger record is current
4. Respect identity protection requirements

## Adding New Vignettes

1. Ensure story exists in Empathy Ledger with proper consent
2. Create file using [vignette template](_templates/vignette-template.md)
3. Tag with ALMA signals and project slugs in frontmatter
4. Set consent scope and cultural sensitivity level
5. Document media needs
6. Add to this index with appropriate categorization
7. Obtain cultural review if required
