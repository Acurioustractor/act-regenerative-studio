# Internal Calls to Action

These are small, repeatable actions that keep the model real. If a call to action cannot be done this week, it is not a call to action.

> "The process is the product. If it is not respectful, the outcome will not be either."

---

## Daily Practice

### For Everyone

- [ ] **Listen first.** If in doubt, pause and return to community voice.
- [ ] **Use LCAA** to structure planning and delivery.
- [ ] **Use ALMA** to check ethics and learning quality.
- [ ] **Keep language grounded** - non-extractive, honest. No savior framing.
- [ ] **Write in ACT voice** - warm, grounded, humble, visionary, professional yet rebellious.
- [ ] **Mark sensitive content** - use [INTERNAL ONLY] for high-nuance partner details.

### For Project Leads

- [ ] **Apply the ACT Core Model** to every project plan and update.
- [ ] **Route impact learning** through Empathy Ledger and ALMA.
- [ ] **Review claims** before external sharing.
- [ ] **Update project status** in Notion weekly.

### For Operations

- [ ] **Keep Harvest and Goods pathways** practical and community-led.
- [ ] **Protect consent and cultural protocols** at every stage.
- [ ] **Monitor land capacity** and adjust pace accordingly.

## ALMA Capture Prompts

Use these in any project update, team meeting, or reflection:

1. **What did we hear, and who holds authority?**
2. **What system-level shift is emerging?**
3. **What harm risk or consent boundary must be held?**
4. **What practical change do we commit to next?**
5. **What should remain internal for now?**

## Ways of Working Checklist

Before any external communication:

- [ ] Is this written in ACT voice?
- [ ] Have we checked consent status?
- [ ] Is Elder review required?
- [ ] Are claims verified?
- [ ] Is shareability status clear?

Before any project decision:

- [ ] Have we listened to community voice?
- [ ] Does this align with LCAA?
- [ ] Have we checked ALMA signals?
- [ ] Is this within land/community capacity?
- [ ] Is handover considered?

## Escalation Paths

### When stuck
1. Pause and document the block
2. Check with accountability partner
3. Escalate to weekly check-in if unresolved
4. Leadership review if urgent

### When uncertain
1. Default to consent-first
2. Default to slower pace
3. Default to community voice
4. Document for later review

### When conflict arises
1. Name it clearly
2. Return to principles
3. Seek shared understanding
4. Escalate if needed
