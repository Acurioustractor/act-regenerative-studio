**A Curious Tractor (ACT) — Regenerative Innovation Studio.**

A public-facing Next.js 15 / React 19 / Tailwind site for a regenerative innovation ecosystem partnering with marginalised — especially First Nations — communities to dismantle extractive systems. The site spans five flagship projects (Empathy Ledger, JusticeHub, Goods, Black Cockatoo Valley, The Harvest) plus an Art program and the ACT Farm on Jinibara Country. It is an editorial/portfolio hybrid carrying living data: 58 projects, 319 storytellers, 5,039 media items, a wiki, blog, events, and residency/CSA enquiry flows.

The design system must support **two coexisting visual languages** on the same codebase:

1. **Bold Documentary** — cinematic, full-bleed dark video heroes, Fraunces light display type, forest-green + clay accents on warm white, 8px sharp corners, editorial rhythm. Used on the homepage and 5 flagship project narratives. Feels like a field journal at scale.
2. **Warm Editorial** — quiet informational treatment. Rounded sand-coloured cards, tan/brown/olive palette, rounded-3xl corners, softer hierarchy. Used on ~33 meta/legal/directory pages. Feels like a thoughtful printed booklet.

Reference moodboard: Neri Oxman, Forensic Architecture, Theaster Gates, Assemble Studio, Naughtyduk. Explicit anti-patterns: no rounded-corner padding soup, no generic card grids, no nonprofit-template energy, no gradient buttons, no decorative blobs.
